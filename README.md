# Personal Portfolio Website 💻

A modern, responsive personal portfolio website designed to showcase my skills, projects, and experience as a Front-End Developer.

## 📌 About the Project

This portfolio provides a professional overview of my front-end development skills and presents my work in a clean, organized, and user-friendly interface. It is built with a focus on responsive design, accessibility, and a smooth user experience.

## ✨ Features

- **Modern UI:** Clean layout with gradient colors and visual effects.
- **Responsive Design:** Layout adapts to different screen sizes.
- **Dark Mode:** Toggle between light and dark themes.
- **About Me:** Section introducing the developer and services.
- **Skills Section:** Displays front-end technologies and tools.
- **Projects Gallery:** Project cards with category filters.
- **Social Links:** Section for connecting with the developer.
- **Arabic Interface:** Right-to-left layout for Arabic content.
- **Accessibility:** Semantic HTML and accessible navigation elements.
